# GeneWeaver
## GPU-Accelerated CRISPR Alignment Engine

GeneWeaver is a high-performance bioinformatics project designed to identify potential CRISPR off-target DNA mutations.

### Technology Stack
- Python
- NumPy
- Biopython
- Numba
- CUDA
- Dask

### Development Plan
- Week 1: CPU Baseline and DNA Sequence Alignment
- Week 2: CUDA Compilation and TUI Dashboard
- Week 3: Distributed Computing using Dask
- Week 4: CUDA Optimization and Final UI

Currently under development.
